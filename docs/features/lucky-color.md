# Feature: สีที่ใช่ (Personalized Daily Lucky Color)

- **ID:** `lucky-color`
- **Route:** `/lucky-color`
- **Folder:** `src/features/lucky-color/`
- **Status:** In scope (Phase 16) — spec ยืนยันแล้ว (2026-11-25) ผู้ใช้กำหนดชื่อ "สีที่ใช่", ให้เลือกวันเกิดได้ตลอดเวลาและผลเปลี่ยนตาม, และยืนยัน Open Questions ทั้งหมดตามที่เสนอ

## Overview
แนะนำสีมงคลของ "วันนี้" ที่เหมาะกับ "วันเกิด" ของผู้ใช้แต่ละคน ด้วยหลักทักษา (วงล้อ 8 ช่อง) ประมวลผลสองชั้น:
ชั้นที่ 1 คือทักษาของวันเกิด ชั้นที่ 2 คือทักษาของวันและเวลาปัจจุบัน แล้วนำสองชั้นมาซ้อนกัน
สีที่หนุนทั้งสองชั้นขึ้นเป็น "สีปังคูณสอง" ส่วนสีที่เป็นกาลกิณีของชั้นใดชั้นหนึ่งถูกตัดทิ้งจากคำแนะนำทั้งหมดและแจ้งเป็น "สีต้องห้ามวันนี้"
ผู้ใช้ไม่ต้องเทียบตารางสีรายวันเอง ผลลัพธ์อ่านจบใน 3 วินาที

> เป็นเนื้อหาเชิงความเชื่อเพื่อความบันเทิง ต้องมีข้อความ "เพื่อความบันเทิงและความสบายใจ ไม่ใช่คำทำนาย" ที่ท้ายหน้าผลลัพธ์

## Requirements

### ก. เลือกวันเกิด (เปลี่ยนได้ตลอด)
- เมื่อเลือกวันเกิดแล้ว ตัวเลือกวันเกิดอยู่บนสุดของหน้าผลลัพธ์ในรูป **รายการดรอปดาวน์** (แสดงวันเกิดที่เลือกอยู่ ไม่กางทั้ง 8 ปุ่ม) **เปลี่ยนได้ทุกเมื่อ** และผลลัพธ์ทั้งหน้า (ส่วนหัว สีปังคูณสอง สีเสริม สีต้องห้าม) **เปลี่ยนตามวันเกิดที่เลือกทันที** ไม่ต้องกดบันทึกหรือโหลดหน้าใหม่
- ครั้งแรกที่เข้า (ยังไม่มีวันเกิดบันทึก) แสดงตัวเลือกวันเกิดเต็มหน้าแทนผลลัพธ์ ตัวเลือก 8 แบบ: อาทิตย์, จันทร์, อังคาร, พุธกลางวัน, พุธกลางคืน (ราหู), พฤหัสบดี, ศุกร์, เสาร์
- มีคำอธิบายสั้น ๆ ว่าพุธกลางวัน/กลางคืนต่างกันอย่างไร (ตามข้อ ข.3)
- ค่าที่เลือกล่าสุดถูกบันทึกต่อบัญชี (หนึ่งค่าต่อผู้ใช้) เป็นวันเกิดตั้งต้นของครั้งถัดไป การเปลี่ยนไม่ต้อง Confirmation (ไม่ใช่การลบ)
- เปลี่ยนแล้วหน้าจอเปลี่ยนทันทีจากค่าในหน้า ส่วนการบันทึกทำเบื้องหลัง ถ้าบันทึกไม่สำเร็จแสดง Toast ข้อผิดพลาด แต่ผลลัพธ์ที่เห็นยังตรงกับตัวเลือก
- ใช้ดูของคนอื่นได้ด้วยการสลับวันเกิด (ผลคำนวณเหมือนกัน) แต่ค่าที่บันทึกคือค่าล่าสุดที่เลือก

### ข. ตรรกะคำนวณ (pure function ใน `utils/` มีเทสต์ใน `tests/`)
1. **วงล้อทักษา (Circular Array Rotation):** เรียงวัน 8 ช่องเป็นวงกลมตามลำดับ
   `อาทิตย์ → จันทร์ → อังคาร → พุธกลางวัน → เสาร์ → พฤหัสบดี → พุธกลางคืน(ราหู) → ศุกร์ → (วนกลับอาทิตย์)`
   ตำแหน่งทักษา 8 ตำแหน่งเรียงตามนี้: `บริวาร, อายุ, เดช, ศรี, มูละ, อุตสาหะ, มนตรี, กาลกิณี`
   วันตั้งต้นของวงล้อ (วันเกิด หรือวันปัจจุบัน) อยู่ตำแหน่ง "บริวาร" แล้วหมุนอาเรย์ให้ตั้งต้นที่วันนั้น วันถัดไปในวงล้อคือตำแหน่งถัดไป
2. **สีประจำวัน** (ค่าเริ่มต้น แก้ได้ที่ Open Question ข้อ 1): อาทิตย์=แดง, จันทร์=เหลือง, อังคาร=ชมพู, พุธกลางวัน=เขียว, พุธกลางคืน=ดำ/เทา, พฤหัสบดี=ส้ม, ศุกร์=ฟ้า/น้ำเงิน, เสาร์=ม่วง
3. **หาวันปัจจุบันตามหลักโหราศาสตร์** จากวันและเวลาของเครื่อง (เขตเวลาท้องถิ่น):
   - **เปลี่ยนวันเวลา 06:00 น.:** เวลา 00:00–05:59 นับเป็นวันก่อนหน้า
   - **พุธกลางคืน (ราหู):** ตั้งแต่ 18:00 น. ของวันพุธ ถึง 05:59 น. ของวันพฤหัสบดี (พุธ 06:00–17:59 = พุธกลางวัน)
4. **กรอง 2 ชั้น (Dual-Layer Filtering)** ให้ B = วงล้อของวันเกิด, T = วงล้อของวันปัจจุบัน:
   - **สีต้องห้าม (Exclusion):** สีของ "กาลกิณี" ใน B และ "กาลกิณี" ใน T (แจ้งแยกว่ามาจากวันเกิดหรือวันนี้) สีที่ต้องห้ามจะไม่ปรากฏในหมวดอื่นเลย (Zero-Conflict)
   - **สีปังคูณสอง (Intersection):** สีที่อยู่ในกลุ่มดี (เดช/ศรี/มนตรี) ทั้งใน B และ T และไม่ถูกตัดโดยข้อบน บอกด้วยว่าหนุนเรื่องอะไรฝั่งวันเกิดและฝั่งวันนี้
   - **สีเสริมตามเรื่อง (Daily Boost):** แยก 3 หมวด การงาน=เดช, การเงิน/โชคลาภ=ศรี, ผู้ใหญ่อุปถัมภ์=มนตรี แต่ละหมวดคือสีของตำแหน่งนั้นใน B รวมกับใน T หักสีต้องห้ามออก
   - หมวดที่หักแล้วไม่เหลือสี แสดง "วันนี้ไม่มีสีเด่นในหมวดนี้" ส่วนปังคูณสองว่างให้แสดง "-" (ไม่ฝืนหาสีมาแสดง)
5. **ตัวอย่างที่คำนวณตามกฎข้างต้น** (คนเกิดวันจันทร์ ตรวจวันพุธกลางวัน): B กาลกิณี=อาทิตย์ (แดง), T กาลกิณี=อังคาร (ชมพู) → สีต้องห้ามคือ แดง (วันเกิด) และ ชมพู (วันพุธ) ตรงกับตัวอย่างในแนวคิด; กลุ่มดีของ B = เขียว/ม่วง/ฟ้า, ของ T = ส้ม/ดำ-เทา/เหลือง → ปังคูณสองว่าง
   > ตัวอย่างข้อความที่ได้มาในแนวคิด (ปังคูณสอง = ฟ้า/น้ำเงิน) **ไม่ตรงกับผลจากสูตรนี้** จึงเป็น Open Question ข้อ 2

### ค. หน้าผลลัพธ์ (Daily Check-in)
- เปิดหน้าแล้วคำนวณจากเวลาปัจจุบันของเครื่องทันที ไม่ต้องกดปุ่ม ไม่เรียกฐานข้อมูลนอกจากอ่านวันเกิด
- ส่วนบนสุด: ดรอปดาวน์วันเกิด 8 แบบ (ข้อ ก.) ที่ทำงานต่อเนื่องกับผลลัพธ์ด้านล่าง
- ส่วนหัว: "สวัสดีวัน<วันปัจจุบัน>! นี่คือสีมงคลสำหรับคนเกิดวัน<วันเกิด> โดยเฉพาะ" (ถ้าเป็นพุธกลางคืนให้ระบุ "คืนวันพุธ (ราหู)")
- 3 ส่วนตามลำดับ: 🌟 สีปังคูณสอง · 💼 เสริมตามเรื่อง (การงาน / การเงินและโชคลาภ / ผู้ใหญ่อุปถัมภ์) · 🚫 สีต้องห้ามวันนี้ (บอกที่มา วันเกิด/วันนี้)
- แต่ละสีแสดงเป็นชิปสี + ชื่อสีภาษาไทย (ไม่พึ่งสีอย่างเดียว เพื่อคนตาบอดสี) ชิปสีเป็นข้อยกเว้นของกฎขาว-ดำ-เทาเพราะเป็นข้อมูลหลักของฟีเจอร์ ส่วนอื่นของหน้ายังเป็นโทนเทา
- ถ้าหน้าเปิดค้างข้ามขอบเขตเวลา (06:00 / 18:00) ให้คำนวณใหม่เมื่อกลับมาที่แท็บ (visibilitychange) ไม่ต้องใช้ตัวจับเวลา
- มี Loading, Error (อ่านวันเกิดไม่ได้ + ปุ่มลองใหม่), Empty State (ยังไม่ตั้งวันเกิด → หน้า Onboarding) และ Toast ตามกฎกลาง

## Open Questions
> **ผู้ใช้ยืนยันทุกข้อตามที่เสนอ (2026-11-25)** ข้อ 1 ใช้ตารางสีค่าเริ่มต้น · ข้อ 2 ยึดสูตร (ปังคูณสองคือสีที่ดีทั้งสองชั้น) · ข้อ 3 พุธกลางคืนเริ่ม 18:00 น. · ข้อ 4 ทำ 3 หมวด · ข้อ 5 เพิ่มการ์ดที่ 6 ในภาพรวมวันนี้ · ข้อ 6 เวอร์ชัน 0.7.0 · ข้อ 7 ไม่ทำการดูวันอื่นล่วงหน้า

1. **ตารางสีประจำวัน:** ใช้ค่าเริ่มต้นข้อ ข.2 ได้ไหม หรือมีตารางของคุณเอง (บางตำราให้หลายสีต่อวัน เช่น พุธกลางวัน เขียว, พุธกลางคืน ดำ/เทา, ศุกร์ ฟ้า/น้ำเงิน)? *เสนอ: ใช้ค่าเริ่มต้น และให้แต่ละวันมีได้หลายชื่อสี (ชิปเดียวกัน)*
2. **ตัวอย่างในแนวคิดไม่ตรงกับสูตร:** ในตัวอย่าง (เกิดจันทร์ × พุธ) ปังคูณสอง = ฟ้า/น้ำเงิน และการงาน = เขียว, ดำ แต่ตามสูตรทักษาของ 2 ชั้น ฟ้าอยู่ฝั่งวันเกิด (มนตรี) เท่านั้น ส่วนดำ/เทาอยู่ฝั่งวันนี้ (ศรี) *เสนอ: ยึดสูตรเป็นหลัก (ปังคูณสองคือสีที่ดีทั้งสองชั้นจริง ๆ) ถ้าตั้งใจให้นิยาม "ปังคูณสอง" ต่างจากนี้ (เช่น ดีในชั้นใดชั้นหนึ่ง + ไม่ขัดอีกชั้น) บอกได้*
3. **เวลาเริ่มพุธกลางคืน:** 18:00 น. ตามข้อ ข.3 ใช่ไหม (บางตำราใช้ 18:00 บางตำราใช้พระอาทิตย์ตก)
4. **หมวด "ความรัก/เสน่ห์"** ที่อยู่ในตัวอย่างข้อความ: แนวคิดหลักกำหนดแค่ 3 หมวด (เดช/ศรี/มนตรี) *เสนอ: ทำ 3 หมวดตามแนวคิด ไม่เพิ่มหมวดความรัก*
5. **การ์ดบนหน้า Portal:** เพิ่ม `todayWidget` ในภาพรวมวันนี้ (แสดงปังคูณสอง 1–2 สี + สีต้องห้าม) ด้วยไหม ใช้กลไกเดิมของ Phase 15 ไม่แตะฟีเจอร์อื่น *เสนอ: เพิ่ม* (ถ้าเพิ่ม ต้องแก้ spec dashboard.md ให้มีการ์ดที่ 6)
6. **เลขเวอร์ชัน:** *เสนอ 0.7.0* (ฟีเจอร์หลักใหม่ ไม่ใช่แค่แดชบอร์ด)
7. ~~ดูวันเกิดของคนอื่น~~ **ตอบแล้ว:** เลือกวันเกิดได้ตลอดและผลเปลี่ยนตาม (ข้อ ก.) ส่วน "ดูวันอื่นล่วงหน้า" (เช่น พรุ่งนี้) *เสนอ: ไม่ทำใน v1*

## Out of Scope
- คำทำนายดวงรายวัน/ราศี/เลขนำโชค, สีตามทักษาแบบเต็ม 8 ตำแหน่งนอกจากเดช/ศรี/มนตรีและกาลกิณี
- แจ้งเตือนสีมงคลรายวัน (push/อีเมล)
- แชร์การ์ดสรุป, ประวัติสีที่เคยแนะนำ
- เลือกวันเกิดจากวันที่ปฏิทิน (v1 เลือกชื่อวันตรง ๆ เพราะพุธกลางวัน/กลางคืนต้องรู้เวลาเกิด)
- หลายโปรไฟล์วันเกิดต่อบัญชี (บันทึกแค่ค่าล่าสุดที่เลือก)
