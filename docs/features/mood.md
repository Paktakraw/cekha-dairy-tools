# Feature: ตัวฉันวันนี้ (Daily Vibe Check)

- **ID:** `mood`
- **Route:** `/mood`
- **Folder:** `src/features/mood/`
- **Status:** In scope (Phase 13) — spec ยืนยันแล้ว (2026-11-19)

## Overview
เช็กอารมณ์ประจำวันด้วยอิโมจิ แตะเลือกไม่กี่ครั้งก็เสร็จ ไม่ต้องพิมพ์ยาว เหมาะกับวัยรุ่น
ดูภาพรวมเป็นปฏิทินอิโมจิรายเดือน มีการ์ดสรุปรายเดือน
และมีการ์ดให้กำลังใจเมื่อเลือกอารมณ์ฝั่งลบ

## Requirements

### 1. เช็กอารมณ์วันนี้ (Vibe Spectrum)
อิโมจิ 5 ระดับ เรียงจากดีไปไม่ดี (คะแนน 5 → 1):

| คะแนน | ID | อิโมจิ | ชื่อที่แสดง | ความหมาย |
|---|---|---|---|---|
| 5 | `hype` | 🤩 | ตัวท็อป / ปังสุด | วันที่อะไรก็เป็นใจ เจอเรื่องดี ๆ |
| 4 | `chill` | 😊 | เรื่อย ๆ / ชิลล์ | สบายใจ ไม่เครียด สุขเล็ก ๆ |
| 3 | `meh` | 😐 | เฉย ๆ / เนือย | วันปกติ แค่ผ่านไปอีกวัน |
| 2 | `drained` | 😩 | เหนื่อย / หมดแบต | เรียนหนัก งานเยอะ นอนน้อย หมดพลัง |
| 1 | `overwhelmed` | 😭 | ดิ่ง / ไม่ไหว | เครียดจัด เศร้า กดดัน อยากพักจากทุกอย่าง |

- หน้าแรกของฟีเจอร์คือ "เช็กอินวันนี้": แตะอิโมจิ 1 ครั้ง = บันทึกทันที (ไม่ต้องกดปุ่มบันทึกแยก)
- วันละ 1 รายการต่อผู้ใช้ เช็กอินซ้ำในวันเดียวกัน = แก้ไขรายการเดิม (upsert) ไม่ใช่เพิ่มใหม่
- ย้อนหลัง: เลือกวันที่ในอดีตจากปฏิทินเพื่อเพิ่ม/แก้ได้ วันในอนาคตบันทึกไม่ได้
- ลบรายการของวันได้ (ต้องมี Confirmation Dialog)

### 2. แท็กบริบท (Quick Context Tags) และข้อความสั้น
หลังแตะอิโมจิ แสดงแท็กให้แตะเลือก (เลือกได้หลายข้อ ไม่บังคับ):
- **เรื่องราว:** การเรียน/สอบ, การเงิน, เพื่อน, ความรัก, ครอบครัว, สุขภาพ/การนอน
- **กิจกรรม:** กินของอร่อย, ฟังเพลง, ดูหนัง/ซีรีส์, ออกกำลังกาย, ช้อปปิ้ง
- ช่องข้อความ 1 บรรทัด ไม่บังคับ ไม่เกิน 100 ตัวอักษร (มีตัวนับ)
- **แท็กตั้งค่าเองได้** (เพิ่มภายหลัง 2026-11-19 ตามที่ผู้ใช้ขอ) ดูหัวข้อ 6 "ตั้งค่าแท็ก" แท็กด้านบนเป็นแท็กเริ่มต้นที่ระบบใส่ให้ผู้ใช้ครั้งแรก
- บันทึกแท็ก/ข้อความเมื่อกดปุ่ม "บันทึก" (จากหน้า "วันนี้" เมื่อบันทึกสำเร็จจะพาไปแท็บ "ปฏิทิน" อัตโนมัติ; ถ้าล้มเหลวค้างที่ฟอร์มพร้อมข้อความ error; จากปฏิทิน (Popup ย้อนหลัง) เมื่อบันทึกสำเร็จจะปิด Popup กลับมาที่ปฏิทิน) (ปุ่มไอคอน + Tooltip + aria-label); อิโมจิถูกบันทึกไปแล้วตั้งแต่แตะ

### 3. สรุปรายเดือน (Visual Monthly Recap)
- **ปฏิทินอิโมจิ:** ตารางรายเดือน แต่ละวันแสดงอิโมจิของวันนั้น วันที่ยังไม่เช็กอินแสดงว่าง กดวันเพื่อดู/แก้รายการ เลื่อนเดือนก่อนหน้า/ถัดไปได้ (ถัดไปไม่เกินเดือนปัจจุบัน)
- **การ์ดสรุปรายเดือน (Monthly Vibe Card):**
  - สัดส่วนอารมณ์ทั้ง 5 ระดับเป็นเปอร์เซ็นต์ (คิดจากจำนวนวันที่เช็กอินในเดือนนั้น)
  - อารมณ์ที่เจอบ่อยที่สุด, จำนวนวันที่เช็กอิน, แท็กที่พบบ่อยที่สุด 3 อันดับ
  - ข้อความให้กำลังใจ 1 ข้อความ เลือกตามอารมณ์เด่นของเดือน (ชุดข้อความคงที่ในโค้ด ไม่มี AI) ไม่มีปุ่มแชร์/สร้างภาพ (ผู้ใช้ตัดออก)
  - เดือนที่เช็กอินน้อยกว่า 5 วัน แสดงการ์ดได้ แต่ขึ้นหมายเหตุว่าข้อมูลยังน้อย
- เดือนที่ไม่มีข้อมูล = Empty State ชวนไปเช็กอิน

### 4. Instant Vibe Boost
เมื่อบันทึกอารมณ์ **😩 หรือ 😭** จะแสดงการ์ดปลอบใจ (ปิดได้ ไม่บังคับอ่าน):
- ข้อความปลอบใจสั้น ๆ สุ่ม 1 ข้อความจากชุดคงที่ของแต่ละระดับ
- ข้อเสนอแนะกิจกรรมเล็ก ๆ ที่ทำได้เลยโดยไม่ต้องใช้ฟีเจอร์อื่น (เช่น พักสายตา 10 นาที ดื่มน้ำ ยืดเส้น)
- ปุ่มลิงก์ไปฟีเจอร์ที่ **มีอยู่จริงแล้ว** เช่น "สุ่มเมนูฮีลใจ" ไปหน้า `/randomizer` (เป็นเพียงลิงก์ ไม่ import โค้ดข้ามฟีเจอร์ ตามข้อ 4.1)
- 😭 ต่อเนื่อง 3 วันขึ้นไป: เพิ่มข้อความเบา ๆ แนะนำให้คุยกับคนที่ไว้ใจหรือผู้เชี่ยวชาญ พร้อมหมายเหตุว่าแอปนี้ไม่ใช่เครื่องมือวินิจฉัยหรือแทนการรักษาทางการแพทย์ พร้อมเบอร์สายด่วนสุขภาพจิต กรมสุขภาพจิต **1323** (โทรฟรี 24 ชม. — ตรวจแหล่งอ้างอิงล่าสุดก่อนใส่ในโค้ด)

### Validation
- วันที่ต้องไม่เกินวันนี้ (ตามเวลาท้องถิ่นของผู้ใช้)
- อารมณ์ต้องเป็นหนึ่งใน 5 ระดับ; แท็กของรายการต้องเป็นแท็กของผู้ใช้เองที่ยังมีอยู่ ไม่ซ้ำกัน และไม่เกิน 30 อัน
- ข้อความ ≤ 100 ตัวอักษร (ตัดช่องว่างหัวท้าย; ว่าง = ไม่มี)
- บังคับระดับ Database ด้วย (CHECK/UNIQUE)

### 6. ตั้งค่าแท็ก (แท็บ "ตั้งค่า")
- แท็บที่ 4 ของฟีเจอร์ แบ่ง 2 กลุ่ม: **เรื่องราว** และ **กิจกรรม** แสดงแท็กของผู้ใช้ทั้งหมดในแต่ละกลุ่ม
- **เพิ่ม** แท็กใหม่ในกลุ่มที่เลือก, **แก้ชื่อ**, **ลบ** ได้ทุกแท็ก รวมแท็กเริ่มต้น 11 อัน (ปุ่มไอคอน + Tooltip + aria-label)
- ลบแท็กต้องมี Confirmation Dialog บอกว่าแท็กจะถูก**ถอดออกจากรายการเช็กอินเก่าทุกวัน**ด้วย (สรุปเดือนของเดือนเก่าจะไม่นับแท็กนั้น)
- ข้อจำกัด: ชื่อ 1–20 ตัวอักษร (ตัดช่องว่างหัวท้าย), ชื่อห้ามซ้ำในกลุ่มเดียวกัน (ไม่สนตัวพิมพ์/ช่องว่างหัวท้าย), รวมไม่เกิน **30 แท็ก** ต่อผู้ใช้ (บังคับที่ฐานข้อมูลด้วย)
- แท็กเริ่มต้น 11 อันถูกใส่ให้ผู้ใช้อัตโนมัติเมื่อเปิดฟีเจอร์ครั้งแรกที่ยังไม่มีแท็กเลย (เหมือน seed ของ Finance/Calorie: ถ้าลบจนหมดแล้วกลับมาเปิดใหม่ แท็กเริ่มต้นจะกลับมา)
- ลำดับแสดงตามลำดับที่เพิ่ม (ไม่มีการจัดลำดับเองใน v1)
- หน้าเลือกแท็กตอนเช็กอินแสดงแท็กจากรายการของผู้ใช้ ถ้ายังไม่มีแท็กเลยแสดงข้อความชวนไปเพิ่มที่แท็บ "ตั้งค่า"

### 5. เตือนให้เช็กอิน
- ไม่มีการแจ้งเตือนนอกแอป เมื่อเข้ามาที่หน้าของฟีเจอร์ (แท็บ "วันนี้") ถ้ายังไม่เช็กอินวันนี้ แสดงแถบเตือน "วันนี้ยังไม่ได้เช็กอิน" ที่ส่วนของฟีเจอร์เอง (ไม่แตะหน้า Portal เพราะห้ามฟีเจอร์ข้ามกัน)

### UI
- Layout เดียวกับฟีเจอร์อื่น (Sidebar/Header) แท็บย่อย: **วันนี้ · ปฏิทิน · สรุปเดือน · ตั้งค่า**
- มี Loading, Error, Empty State, Toast ตามกฎกลาง และรองรับโหมดมืด
- สีของระดับอารมณ์ (ถ้าอนุมัติ) ใช้โทนหม่น ข้อมูลสำคัญต้องอ่านได้จากอิโมจิ/ตัวอักษรด้วย ไม่พึ่งสีอย่างเดียว

## Database
ตาราง `mood_entries` และ `mood_tags` (+ คอลัมน์มาตรฐานตาม CLAUDE.md ข้อ 6)

| Field | Type | Rule |
|---|---|---|
| entry_date | date | NOT NULL |
| mood | smallint | NOT NULL, CHECK 1–5 (1=ดิ่ง … 5=ปังสุด) |
| tags | text[] | NOT NULL DEFAULT '{}' เก็บ id (uuid ในรูปข้อความ) ของ `mood_tags`; CHECK ไม่ซ้ำ + `cardinality ≤ 30`; trigger ตรวจว่าทุก id เป็นแท็กของผู้ใช้เองที่ยังมีอยู่ |
| note | text | NULL, CHECK `char_length(note) between 1 and 100` |

- `UNIQUE (user_id, entry_date)` — วันละ 1 รายการ
- CHECK `entry_date <= current_date + 1` (กันวันอนาคต โดยเผื่อ timezone ของเซิร์ฟเวอร์ที่เป็น UTC; การตรวจเข้มงวดทำฝั่ง client)
- RLS 4 policies `auth.uid() = user_id`, trigger `set_updated_at`
- Index: `user_id`, `(user_id, entry_date)` (จาก UNIQUE ใช้ได้เลย)
- Migration: `supabase/migrations/<timestamp>_mood.sql` (ไฟล์ใหม่ ไม่แก้ไฟล์เดิม)
- upsert ผ่าน `insert ... on conflict (user_id, entry_date) do update`

ตาราง `mood_tags` (migration ที่ 2 `<timestamp>_mood_custom_tags.sql`)

| Field | Type | Rule |
|---|---|---|
| group_kind | text | NOT NULL, CHECK ∈ (`story`, `activity`) |
| name | text | NOT NULL, ตัดช่องว่างแล้วไม่ว่าง, ≤ 20 ตัวอักษร |
| sort_order | integer | NOT NULL ตั้งอัตโนมัติ (ลำดับถัดไปในกลุ่ม) |

- UNIQUE `(user_id, group_kind, lower(btrim(name)))`; Index `user_id`; RLS 4 policies + trigger `set_updated_at`
- trigger ก่อน INSERT: จำกัด 30 แท็กต่อผู้ใช้ และตั้ง `sort_order`
- trigger หลัง DELETE: ถอด id ของแท็กออกจาก `mood_entries.tags` ของผู้ใช้ (security invoker)
- RPC `seed_default_mood_tags()` (security invoker, idempotent, revoke จาก public/anon): ใส่แท็กเริ่มต้น 11 อันถ้าผู้ใช้ยังไม่มีแท็ก
- migration ที่ 2 แปลงข้อมูลเดิมจาก migration แรก (แท็กแบบ id คงที่) ให้เป็นแท็กของผู้ใช้ที่มีรายการเช็กอินอยู่แล้ว

## Pure functions (`utils/`, มีเทสต์ใน `tests/mood.test.ts`)
- สร้างตารางปฏิทินของเดือน (ช่องว่างก่อนวันที่ 1, จำนวนวัน, เริ่มสัปดาห์วันอาทิตย์หรือจันทร์ ดู Open Questions)
- นับสัดส่วนอารมณ์เป็น % (รวมกัน 100 โดยใช้ largest remainder), หาอารมณ์เด่น (กรณีเสมอ เลือกตามกฎที่กำหนดไว้)
- แท็กยอดนิยม Top 3
- เลือกข้อความให้กำลังใจ/ปลอบใจ (รับค่าสุ่มเป็นพารามิเตอร์ เพื่อให้เทสต์ได้)
- ตรวจ "ดิ่งต่อเนื่อง N วัน"
- Validation ของ input, ตรวจวันอนาคต

## Decisions (ผู้ใช้ตอบ Open Questions เมื่อ 2026-11-19)
> เพิ่มภายหลัง (2026-11-19): ผู้ใช้ขอเมนูตั้งค่าให้เพิ่ม "เรื่องราว/กิจกรรม" เองได้ ตอบว่า ลบแท็กแล้วถอดออกจากรายการเก่าด้วย, แก้ชื่อ/ลบได้ทุกแท็กรวมแท็กเริ่มต้น, ชื่อ ≤ 20 ตัวอักษร รวม ≤ 30 แท็ก ชื่อห้ามซ้ำในกลุ่ม (ดูหัวข้อ 6)

1. ตัดเรื่องการดื่มน้ำ/กราฟเทียบอารมณ์กับน้ำออกจาก v1 (ทำภายหลังเมื่อมีฟีเจอร์ดื่มน้ำ)
2. ใช้ข้อความแนะนำ + ลิงก์ไป `/randomizer` แทนเสียงฝน/Focus
3. ขยายข้อยกเว้นสีของ CLAUDE.md ข้อ 5: ใช้โทนหม่น 5 ระดับตามอารมณ์ เฉพาะพื้นหลังช่องปฏิทิน/แถบสัดส่วน (เขียว→เขียวอ่อน→เทา→ส้ม→แดงหม่น) รองรับโหมดมืด
4. ไม่มีปุ่มแชร์/ภาพ 9:16 (ยกเลิก)
5. ปฏิทินเริ่มวันอาทิตย์
6. ใส่เบอร์สายด่วนสุขภาพจิต 1323 เมื่อเลือก 😭 ต่อเนื่อง
7. ผมร่างข้อความให้กำลังใจ/ปลอบใจภาษาวัยรุ่น ผู้ใช้ปรับภายหลังได้
8. แจ้งเตือนเช็กอินแสดงในส่วนของฟีเจอร์เองเมื่อเข้าแอป (ดูข้อ 5 ของ Requirements)

## Out of Scope
- ฟีเจอร์ดื่มน้ำและกราฟเทียบอารมณ์กับน้ำ (ดู Open Questions ข้อ 1)
- โหมด Focus / เสียงฝน / เพลง, การวิเคราะห์อารมณ์ด้วย AI, การให้คำปรึกษาหรือวินิจฉัยทางจิตเวช
- การแชร์ข้อมูลกับผู้ใช้อื่น/เพื่อน, Social feed, Streak/เหรียญรางวัล
- การแชร์เป็นภาพ/เชื่อม Instagram/TikTok (ผู้ใช้ตัดออก)
- การแจ้งเตือนนอกแอป, ส่งออกข้อมูล, การจัดลำดับแท็กเอง, ไอคอน/สีของแท็ก
