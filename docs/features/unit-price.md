# Feature: Unit Price Comparator (เทียบราคาต่อหน่วย)

- **ID:** `unit-price`
- **Route:** `/unit-price`
- **Folder:** `src/features/unit-price/`
- **Status:** In scope (Phase 9) — ตอบ Open Questions แล้ว (2026-11-12) รอผู้ใช้พิมพ์ "ยืนยัน spec"

## Overview
เครื่องมือช่วยตัดสินใจตอนช้อปปิ้ง ผู้ใช้กรอกราคาและปริมาณของสินค้า 2–3 ตัวเลือก
ระบบคำนวณราคาต่อหน่วย (เช่น ต่อกรัม ต่อมิลลิลิตร ต่อชิ้น) แล้วบอกทันทีว่าตัวเลือกไหนคุ้มที่สุด และแพงกว่ากี่ %

## Requirements

### การกรอกข้อมูล
- มีตัวเลือกเริ่มต้น 2 ช่อง ผู้ใช้เพิ่มได้ถึง 3 ช่อง และลบช่องที่เกิน 2 ได้ (ต้องเหลืออย่างน้อย 2)
- แต่ละตัวเลือกกรอก: ชื่อ (ไม่บังคับ เช่น "ยี่ห้อ A"), ราคา (บาท), ปริมาณ, หน่วย
- ไม่มีช่องจำนวนแพ็ก: ถ้าซื้อเป็นแพ็ก (เช่น 6 กระป๋อง × 330 มล.) ให้ผู้ใช้กรอกปริมาณรวมเอง (1,980 มล.)
- ผลลัพธ์อัปเดตทันทีที่กรอก ไม่ต้องกดปุ่มคำนวณ และไม่ต้องบันทึก

### หน่วยที่รองรับ
| กลุ่ม | หน่วยที่เลือกได้ | หน่วยฐานสำหรับคำนวณ |
|---|---|---|
| น้ำหนัก | มิลลิกรัม (มก.), กรัม (ก.), กิโลกรัม (กก.) | กรัม |
| ปริมาตร | มิลลิลิตร (มล.), ลิตร (ล.) | มิลลิลิตร |
| นับจำนวน | ชิ้น | ชิ้น |

- เทียบได้เฉพาะตัวเลือกที่อยู่ในกลุ่มเดียวกัน (เช่น กรัมเทียบกับกิโลกรัมได้ แต่กรัมเทียบกับมิลลิลิตรไม่ได้)
- ถ้าผู้ใช้เลือกคนละกลุ่ม ให้แสดงข้อความอธิบายและไม่จัดอันดับ
- ผู้ใช้เลือกหน่วยของแต่ละตัวเลือกได้อิสระภายในกลุ่มเดียวกัน (ตัวเลือก A เป็นกรัม ตัวเลือก B เป็นกิโลกรัม ได้)

### ผลลัพธ์
- ราคาต่อหน่วยของแต่ละตัวเลือก แสดงตาม **หน่วยผลลัพธ์ที่ผู้ใช้เลือกเอง** (Dropdown):
  - กลุ่มน้ำหนัก: ต่อ 1 กรัม / ต่อ 100 กรัม (ค่าเริ่มต้น) / ต่อ 1 กิโลกรัม
  - กลุ่มปริมาตร: ต่อ 1 มิลลิลิตร / ต่อ 100 มิลลิลิตร (ค่าเริ่มต้น) / ต่อ 1 ลิตร
  - กลุ่มนับจำนวน: ต่อ 1 ชิ้น (ตัวเลือกเดียว)
  - เปลี่ยนหน่วยผลลัพธ์แล้วตัวเลขอัปเดตทันที ส่วนการจัดอันดับ/% ที่แพงกว่าไม่เปลี่ยน
- ไฮไลต์ตัวเลือกที่ถูกที่สุดต่อหน่วย พร้อมป้าย "คุ้มที่สุด"
- ตัวเลือกอื่นแสดง "แพงกว่า X%" เทียบกับตัวที่ถูกที่สุด
- ถ้าราคาต่อหน่วยเท่ากัน (ต่างกันไม่เกินความคลาดเคลื่อนทศนิยม) ให้แสดง "ราคาเท่ากัน" ไม่ชี้ว่าตัวไหนถูกกว่า
- ตัวเลือกที่กรอกไม่ครบหรือไม่ถูกต้องไม่ถูกนำไปจัดอันดับ และแสดงข้อความบอกว่าขาดอะไร
- ต้องมีตัวเลือกที่กรอกครบอย่างน้อย 2 ตัวจึงจัดอันดับได้

### Validation
- ราคา: > 0 และ ≤ 1,000,000 (ทศนิยมไม่เกิน 2 ตำแหน่ง)
- ปริมาณ: > 0 และ ≤ 1,000,000
- ชื่อ: ไม่เกิน 50 ตัวอักษร

### Technical Notes
- คำนวณทั้งหมดฝั่ง Client เป็น pure function ใน `utils/` ไม่ผูกกับ UI และมีเทสต์ใน `tests/`
  - แปลงหน่วย (มก./ก./กก., มล./ล.) → หน่วยฐาน
  - ราคาต่อหน่วยฐาน = ราคา ÷ (ปริมาณ × ตัวคูณหน่วย) แล้วคูณด้วยขนาดหน่วยผลลัพธ์ที่เลือก
  - จัดอันดับ, หาตัวถูกที่สุด, % ที่แพงกว่า, ตรวจกลุ่มหน่วยไม่ตรงกัน, ตรวจราคาเท่ากันด้วย tolerance
- ไม่มีการเรียก Supabase ในเวอร์ชันนี้ จึงไม่มี Loading/Error ฝั่งข้อมูล (มี Empty State ก่อนกรอกครบ และ Toast ตามความเหมาะสม)
- ข้อความ UI ทั้งหมดเป็นภาษาไทย, ปุ่มเพิ่ม/ลบใช้ไอคอน + Tooltip + aria-label ตามกฎกลาง
- ลบตัวเลือกไม่ต้องมี Confirmation Dialog เพราะเป็นข้อมูลชั่วคราวที่ยังไม่ได้บันทึก

## Database
ไม่มีตารางในเวอร์ชันนี้ (ไม่มี migration)
หากผู้ใช้ต้องการบันทึกประวัติการเปรียบเทียบ จะเพิ่มตาราง `unit_price_comparisons` ใน Phase แยกตามข้อ 6 ของ CLAUDE.md

## Suggested Components
- Components: `OptionCard` (ฟอร์มหนึ่งตัวเลือก), `ResultSummary` (ผลลัพธ์/ป้ายคุ้มที่สุด), Dropdown เลือกหน่วยผลลัพธ์
- Hooks: `useComparison` (state ของตัวเลือก + ผลลัพธ์ที่คำนวณจาก pure function)
- Utils: `units.ts` (กลุ่มหน่วย ตัวคูณ และหน่วยผลลัพธ์ที่เลือกได้), `unitPrice.ts` (คำนวณ/จัดอันดับ)
- Services: ไม่มี
- Pages: `UnitPricePage`
- Registry: id `unit-price`, ชื่อ "เทียบราคาต่อหน่วย", icon `Scale` (lucide)

## Decisions (ผู้ใช้ตอบ Open Questions เมื่อ 2026-11-12)
1. ไม่เก็บประวัติลง Supabase ใน v1 (ไม่มีตาราง/migration)
2. ตัวเลือกสูงสุด 3 (เริ่มที่ 2)
3. ไม่มีช่องจำนวนแพ็ก
4. ผู้ใช้เลือกหน่วยผลลัพธ์เองได้ (ค่าเริ่มต้นต่อ 100 ก./100 มล.)
5. หน่วยนับใช้ "ชิ้น" คำเดียว
6. ชื่อเมนู "เทียบราคาต่อหน่วย" และ path `/unit-price`

## Out of Scope
- การดึงราคาจากร้านค้าหรือบาร์โค้ด, API ภายนอก
- หน่วยความยาว/พื้นที่ (เช่น เมตร, ตร.ม.) และการแปลงหน่วยแบบอังกฤษ (ออนซ์, ปอนด์)
- สกุลเงินอื่นนอกจากบาท และส่วนลด/โปรโมชั่น (เช่น ซื้อ 1 แถม 1 ให้ผู้ใช้คำนวณปริมาณรวมเอง)
- การบันทึกประวัติ และช่องจำนวนแพ็ก (ผู้ใช้ตัดสินใจไม่ทำใน v1)
