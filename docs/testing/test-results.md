## 6. สิ่งที่ยังไม่ได้ทดสอบ และปัญหาที่ยังเปิดอยู่
| เรื่อง | รายละเอียด |
|---|---|
| หน้าจอจริงบนอุปกรณ์ | Responsive มือถือ/แท็บเล็ต และโหมดมืดของ ตัวฉันวันนี้ (รวมสีพื้นระดับอารมณ์ 5 ระดับ), อย่าลืมฉัน, ไซส์ไหนคือฉัน, อันไหนถูกกว่า บอกมา และ Calorie **ยังไม่ได้ตรวจด้วยตา** (PROGRESS.md Known Issues) การปรับเลย์เอาต์แถวเมนูของไซส์ไหนคือฉันหลายรอบ ผู้ใช้ตรวจเอง ไม่มีบันทึกผล |
| Supabase จริง | ฟังก์ชัน seed, upsert โปรไฟล์/ธีม และ RPC `complete_reminder` ของ อย่าลืมฉัน ทดสอบเฉพาะบน PostgreSQL ชั่วคราว |
| บัญชีผู้ใช้ (Phase 14) | เคส `TC-DB-17–24` (trigger/RPC/RLS/CHECK รายข้อ) ยังไม่ได้ทดสอบ, ขั้นตอน SQL ใน [admin-password-reset.md](../admin-password-reset.md) ผู้ใช้ทดลองตั้งรหัสใหม่แล้วแต่ต้องเปลี่ยน role เป็น `postgres` (แก้คู่มือแล้ว), หน้าจอมือถือ/Sidebar ย่อ/กล่องออกจากระบบใน Sidebar ไม่มีบันทึกผลรายข้อ |
| UI/E2E | ไม่มีเทสต์อัตโนมัติ |
| ตารางไซส์เสื้อผ้า | เป็นค่าประมาณจากหลายแหล่งที่ไม่ตรงกัน (ไซส์ JP ไม่ชัด) ยังไม่ได้เทียบกับตารางของแบรนด์จริง |
| ตัวคูณกิจกรรม TDEE | ยังไม่ได้เทียบกับบทความอ้างอิงเดิม (เปิดไม่ได้) |
