## วิธีอ่าน
- **รหัสเคส** `TC-<ฟีเจอร์>-A<เลข>` = เทสต์อัตโนมัติ (รันด้วย `npm test`) · `TC-<ฟีเจอร์>-M<เลข>` = เคสทำด้วยมือ
- **ฟีเจอร์** ตรงกับรหัสใน [PRD](../spec/PRD.md) หัวข้อ 4 (TODO, RND, FIN, CAL, UP, EXP, SZ, MOOD, THM, APP)
- เคสอัตโนมัติระบุไฟล์เทสต์และกลุ่ม (`describe`) เพื่อไปหาโค้ดได้ ส่วนเคสทำด้วยมือเป็นข้อความตามเช็กลิสต์เดิม (ผลที่คาดหวังอยู่หลังเครื่องหมาย →)
- เคสที่ตรวจที่ฐานข้อมูลโดยตรง (RLS, CHECK, RPC) ดูหัวข้อ "เคสฐานข้อมูล" ท้ายไฟล์

## การอัปเดตเอกสารนี้
เพิ่ม/แก้/ลบเทสต์ใน `tests/` หรือเช็กลิสต์ใน `docs/testing.md` แล้วต้องอัปเดตไฟล์นี้ให้ตรง (เพิ่มแถวใหม่ท้ายกลุ่มของฟีเจอร์ ไม่เปลี่ยนเลขของเคสเดิมเพื่อให้อ้างอิงข้ามเอกสารได้) และต้องอัปเดตผลใน [test-results.md](test-results.md) ก่อนเปิด PR (ดู [CLAUDE.md](../../CLAUDE.md) ข้อ 10.11)
