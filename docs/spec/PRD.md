## 1. สรุปสั้น ๆ
เสขาประจำวันคือเว็บแอปที่รวมเครื่องมือเล็ก ๆ สำหรับชีวิตประจำวันไว้ในที่เดียว เปิดแอปแล้วเห็นการ์ดของแต่ละเครื่องมือ กดเข้าไปใช้ได้เลย ไม่ต้องสมัครสมาชิก ใช้ได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์ ข้อความทั้งหมดเป็นภาษาไทย

## 2. ปัญหาที่แก้และเป้าหมาย
| ปัญหาของผู้ใช้ | สิ่งที่แอปทำให้ |
|---|---|
| เครื่องมือชีวิตประจำวันกระจายอยู่หลายแอป | รวมไว้ที่เดียว หน้าตาและวิธีใช้เหมือนกันทุกเครื่องมือ |
| แอปทั่วไปซับซ้อนเกินจำเป็น | เรียบง่าย ขาว-ดำ-เทา ทำเฉพาะสิ่งที่ต้องใช้ |
| ไม่อยากเสียเวลาสมัครสมาชิก | เปิดแล้วใช้ได้ทันที และเพิ่มระบบสมัคร/เข้าสู่ระบบทีหลังได้โดยข้อมูลเดิมไม่หาย |
| อยากได้เครื่องมือใหม่เพิ่มเรื่อย ๆ | เพิ่มเครื่องมือใหม่ได้โดยไม่กระทบของเดิม |

**ถือว่าสำเร็จเมื่อ**
- ผู้ใช้ใหม่เปิดแอปแล้วใช้ได้ทันที
- ข้อมูลของแต่ละคนเป็นส่วนตัว คนอื่นมองไม่เห็น
- ทุกหน้ามีสถานะกำลังโหลด, เกิดข้อผิดพลาด (พร้อมปุ่มลองใหม่), ยังไม่มีข้อมูล และข้อความแจ้งผลหลังทำรายการ
- ก่อนส่งงานทุกครั้ง การตรวจโค้ดอัตโนมัติ การ build และชุดเทสต์ผ่านทั้งหมด

## 3. ผู้ใช้
ข้อมูลนี้มาจากเจ้าของผลิตภัณฑ์ ไม่ได้มาจากการสำรวจผู้ใช้จริง
- **คนไทยทั่วไป** ที่อยากได้เครื่องมือง่าย ๆ ในชีวิตประจำวัน (กลุ่มหลัก)
- **วัยรุ่นและคนรุ่นใหม่ที่สั่งของจากต่างประเทศ** (เครื่องมือ "ไซส์ไหนคือฉัน")
- **วัยรุ่นที่อยากเช็กใจตัวเองเร็ว ๆ ไม่ต้องพิมพ์ยาว** (เครื่องมือ "ตัวฉันวันนี้")

## 5. กติกาที่ใช้เหมือนกันทุกเครื่องมือ
- ข้อความทุกอย่างที่ผู้ใช้เห็นเป็นภาษาไทย
- หน้าตาเรียบง่าย ขาว-ดำ-เทา ใช้สีเขียว/แดงเฉพาะที่ช่วยให้อ่านง่าย (เช่น ตัวเลขรายรับ-รายจ่าย สถานะวันครบกำหนด)
- ปุ่มสั่งงานเป็นไอคอน มีคำอธิบายเมื่อชี้เมาส์
- ทุกการลบมีหน้าต่างให้ยืนยันก่อน
- ข้อมูลที่สำคัญถูกตรวจทั้งที่หน้าจอและที่ฐานข้อมูล (เช่น ชื่อห้ามซ้ำ จำนวนเงินต้องมากกว่า 0)
- ข้อมูลของแต่ละคนแยกกัน คนอื่นเข้าถึงไม่ได้

## 6. สิ่งที่ยังไม่ทำ
ต้องมีการเขียน spec และได้รับการยืนยันก่อนจึงจะเริ่มทำได้
- ระบบสมัคร/เข้าสู่ระบบด้วยอีเมลหรือบัญชีโซเชียล (ตอนนี้เข้าแบบไม่ระบุตัวตนอัตโนมัติ)
- เครื่องมือ "ลูกหนี้" (คนที่ยืมเงิน) และ "นัดหมาย"
- การเตือนนอกแอป (แจ้งเตือนมือถือ อีเมล LINE) และการล็อกด้วยชีวมิติ ของ "อย่าลืมฉัน"
- การแนบไฟล์ใน "อย่าลืมฉัน"
- ตารางไซส์รายแบรนด์ ไซส์เด็ก และคู่มือวัดตัว ของ "ไซส์ไหนคือฉัน"
- ปุ่มแชร์การ์ดสรุปเป็นภาพลงโซเชียล, กราฟเทียบอารมณ์กับการดื่มน้ำ (ยังไม่มีเครื่องมือดื่มน้ำ), เสียงฝน/โหมดโฟกัส และการแจ้งเตือนเช็กอินนอกแอป การจัดลำดับแท็กเอง ของ "ตัวฉันวันนี้" (ผู้ใช้ตัดออกจากรอบแรก)
- การทดสอบหน้าจออัตโนมัติ

## 7. ข้อจำกัดที่ควรรู้
- **บัญชีแบบไม่ระบุตัวตน:** ถ้าผู้ใช้ล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง จะเข้าถึงข้อมูลเดิมไม่ได้ จนกว่าจะมีระบบเข้าสู่ระบบจริง
- **ตัวเลขแคลอรี่ของอาหารเป็นค่าประมาณ** ที่มายังไม่ได้ตรวจกับแหล่งทางการ แอปแสดงป้าย "ค่าโดยประมาณ"
- **ไซส์เสื้อผ้าเป็นค่าประมาณ** จากหลายแหล่งที่ตัวเลขไม่ตรงกัน โดยเฉพาะไซส์ญี่ปุ่น ไซส์จริงของแบรนด์อาจต่างไปครึ่งไซส์ถึงหนึ่งไซส์
- **การเตือนของ "อย่าลืมฉัน" ทำงานตอนเปิดแอปเท่านั้น** ไม่มีการเตือนเมื่อปิดแอปอยู่
- **"ตัวฉันวันนี้" ไม่ใช่เครื่องมือวินิจฉัยหรือรักษา** ข้อความให้กำลังใจเป็นชุดข้อความสำเร็จรูป (ไม่ใช่ AI) และเก็บอารมณ์ได้วันละครั้งต่อบัญชี
- **ผู้ดูแลต้องรันชุดคำสั่งฐานข้อมูล (migration) เองใน Supabase** ก่อนใช้ฟีเจอร์ใหม่ ยังไม่มีระบบรันให้อัตโนมัติ
- **ยังไม่มีการทดสอบหน้าจออัตโนมัติ** การตรวจหน้าจอบนมือถือและโหมดมืดทำด้วยมือโดยผู้ใช้

## 9. กระบวนการทำงานของโปรเจกต์
1. เครื่องมือใหม่ต้องมี spec และได้รับการยืนยันก่อนเริ่มเขียนโค้ด
2. ทำทีละระยะ ไม่เริ่มระยะถัดไปจนกว่าจะยืนยันระยะปัจจุบัน
3. ก่อน commit ต้องตรวจโค้ดด้วย OpenCodeReview แล้วแจ้งผู้ดูแลก่อนแก้
4. ก่อนเปิด Pull Request ต้องอัปเดตเอกสารในโฟลเดอร์ `docs/spec/` และ `docs/testing/` ให้ตรงกับโค้ด
