## 1. แอปนี้คืออะไร
เสขาประจำวันคือเว็บแอปที่รวมเครื่องมือเล็ก ๆ สำหรับชีวิตประจำวันไว้ในที่เดียว เปิดแอปแล้วเห็นการ์ดของแต่ละเครื่องมือ กดเข้าไปใช้ได้เลย

- ใช้ได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์ (เปิดผ่านเว็บเบราว์เซอร์)
- ข้อความทั้งหมดเป็นภาษาไทย
- ข้อมูลของแต่ละคนเป็นส่วนตัว คนอื่นมองไม่เห็น
- หน้าตาเรียบง่าย ขาว-ดำ-เทา

**เครื่องมือที่มี (8 รายการ)**

| ชื่อที่เห็นในแอป | ใช้ทำอะไร |
|---|---|
| วันนี้ทำอะไรดี | จดงานที่ต้องทำและติดตามสถานะ |
| สับสนช่วยหน่อย | สุ่มเลือกจากรายการที่สร้างไว้ เช่น วันนี้กินร้านไหน |
| เงินฉันไปไหน | จดรายรับ-รายจ่าย ดูสรุป |
| ผอมไปด้วยกัน | คำนวณพลังงานที่ใช้ต่อวัน และจดแคลอรี่จากอาหาร |
| อันไหนถูกกว่า บอกมา | เทียบความคุ้มของสินค้า 2–3 ตัวเลือก |
| อย่าลืมฉัน | เตือนเอกสารหมดอายุ งานซ่อมบำรุง ค่าสมาชิก |
| ไซส์ไหนคือฉัน | แปลงสัดส่วนร่างกายเป็นไซส์ของแต่ละประเทศ |
| ตัวฉันวันนี้ | เช็กอารมณ์ประจำวันด้วยอิโมจิ |

และมี **โหมดสว่าง/มืด** กับ **ระบบบัญชีผู้ใช้** (สมัคร เข้าสู่ระบบ ออกจากระบบ) เป็นส่วนกลางของแอป

## 2. เริ่มต้นใช้งาน

### 2.1 สมัครสมาชิก
1. เปิดแอป ถ้ายังไม่ได้เข้าสู่ระบบ ระบบจะพาไปหน้า **เข้าสู่ระบบ** ให้กดลิงก์ไปหน้า **สมัครสมาชิก**
2. กรอกข้อมูลให้ครบทุกช่อง

| ช่อง | ข้อกำหนด |
|---|---|
| ชื่อจริง / นามสกุล | ต้องกรอก |
| ชื่อผู้ใช้ | 3–30 ตัว ใช้ได้เฉพาะตัวอักษรอังกฤษพิมพ์เล็ก ตัวเลข `_` และ `.` ห้ามซ้ำกับคนอื่น |
| อีเมล | รูปแบบอีเมลที่ถูกต้อง ห้ามซ้ำกับคนอื่น |
| เบอร์โทร | เบอร์ไทย 10 หลัก ห้ามซ้ำกับคนอื่น |
| รหัสผ่าน | อย่างน้อย 8 ตัวอักษร (ภาษาไทยนับตัวละ 3 หน่วย จึงยาวสุดราว 24 ตัว) |
| ยืนยันรหัสผ่าน | ต้องตรงกับรหัสผ่าน |

3. กดสมัคร ถ้าสำเร็จจะเข้าสู่ระบบและเห็นหน้าหลักทันที
4. ถ้าชื่อผู้ใช้ อีเมล หรือเบอร์โทรซ้ำกับคนอื่น ระบบจะบอกว่า **ช่องไหน** ซ้ำ ให้แก้แล้วกดใหม่

### 2.2 เข้าสู่ระบบ
1. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** (ไม่ใช้อีเมลเข้าสู่ระบบ)
2. ถ้ากรอกผิด ระบบจะแจ้งรวม ๆ ว่าเข้าสู่ระบบไม่สำเร็จ โดยไม่บอกว่าผิดที่ชื่อผู้ใช้หรือรหัสผ่าน (เพื่อความปลอดภัย)
3. เมื่อเข้าสู่ระบบแล้วจะอยู่ในระบบต่อเนื่อง ปิดแล้วเปิดเบราว์เซอร์ใหม่ก็ยังอยู่ จนกว่าจะกดออกจากระบบเอง

### 2.3 ออกจากระบบ
กดปุ่มไอคอนออกจากระบบ (มีชื่อผู้ใช้แสดงอยู่ข้างกัน ที่เมนูด้านข้างหรือเมนูแบบพับบนมือถือ) แล้วกดยืนยันในกล่องข้อความ

### 2.4 ลืมรหัสผ่าน
ตอนนี้ **ยังไม่มีปุ่มลืมรหัสผ่านและยังเปลี่ยนรหัสผ่านเองไม่ได้** ต้องติดต่อผู้ดูแลระบบให้ตั้งรหัสใหม่ให้ (ผู้ดูแลจะขอยืนยันตัวตนด้วยอีเมลและเบอร์โทรที่ใช้สมัคร) ข้อมูลที่จดไว้ไม่หายเมื่อเปลี่ยนรหัส ขั้นตอนของผู้ดูแลอยู่ที่ [admin-password-reset.md](admin-password-reset.md)

## 3. ส่วนประกอบของหน้าจอ

### 3.1 หน้าหลัก (Portal)
แสดงการ์ดของทุกเครื่องมือ กดการ์ดเพื่อเข้าไปใช้งาน

### 3.2 เมนูสลับเครื่องมือ
- **คอมพิวเตอร์:** เมนูอยู่ด้านซ้ายตลอดเวลา ย่อ/ขยายได้
- **มือถือ/แท็บเล็ต:** มีแถบด้านบน กดไอคอนเมนูเพื่อเปิดรายการเครื่องมือ

### 3.3 โหมดสว่าง/มืด
กดปุ่มรูป **พระอาทิตย์** (สว่าง) หรือ **พระจันทร์** (มืด) ที่เมนู เปลี่ยนทันทีโดยไม่โหลดหน้าใหม่ ระบบจำค่าที่เลือกไว้กับบัญชีของคุณ (เปิดแอปครั้งแรกเป็นโหมดสว่างเสมอ)

### 3.4 สิ่งที่เหมือนกันทุกเครื่องมือ
| เรื่อง | สิ่งที่เห็น |
|---|---|
| ปุ่มสั่งงาน | เป็นไอคอน (เพิ่ม แก้ไข ลบ บันทึก ยกเลิก) ชี้เมาส์ค้างไว้เพื่อดูคำอธิบาย |
| การลบ | มีกล่องถามยืนยันก่อนลบทุกครั้ง |
| กำลังโหลด | แสดงวงกลมหมุน |
| เกิดข้อผิดพลาด | แสดงข้อความพร้อมปุ่ม **ลองใหม่** |
| ยังไม่มีข้อมูล | แสดงข้อความบอกว่ายังว่างอยู่ |
| ทำรายการเสร็จ | มีข้อความเล็ก ๆ (Toast) ขึ้นมาแจ้งผล |
| สี | เขียว/แดงโทนหม่นใช้เฉพาะตัวเลขรายรับ-รายจ่าย ป้าย "คุ้มที่สุด" และสถานะวันครบกำหนด |

## 4. วันนี้ทำอะไรดี — จดงานที่ต้องทำ

**ใช้ทำอะไร:** จดงาน ติดตามว่าอยู่สถานะไหน ดูว่าเสร็จเมื่อไร

### เพิ่มงาน
1. กดปุ่ม **เพิ่มงาน** (ไอคอน +) ที่มุมขวาบน ปุ่มนี้ติดอยู่กับหัวหน้าจอแม้เลื่อนรายการ
2. กรอก **ชื่องาน** (ต้องกรอก ไม่เกิน 100 ตัวอักษร) และ **รายละเอียด** (ไม่บังคับ ไม่เกิน 1,000 ตัวอักษร มีตัวนับให้)
3. กดบันทึก งานใหม่จะอยู่สถานะ "รอดำเนินการ"

**ข้อควรรู้:** ชื่องานห้ามซ้ำกัน (ไม่สนตัวพิมพ์เล็ก/ใหญ่และช่องว่างหัวท้าย)

### เปลี่ยนสถานะ
ในแต่ละงานมีเมนูเลือกสถานะ: **รอดำเนินการ → กำลังทำ → เสร็จแล้ว** เมื่อเลือก "เสร็จแล้ว" ระบบบันทึกวัน-เวลาที่เสร็จให้เอง ถ้าเปลี่ยนกลับเป็นสถานะอื่น เวลาที่เสร็จจะถูกล้าง

### ดูรายละเอียด แก้ไข ลบ
- กดที่งานเพื่อขยายดูรายละเอียดเต็ม
- ปุ่มแก้ไขใช้แก้ชื่อและรายละเอียด
- ปุ่มลบจะถามยืนยันก่อน

### กรองและเปลี่ยนหน้า
- ปุ่มสถานะด้านบนเลือกได้หลายสถานะพร้อมกัน ไม่เลือกเลย = แสดงทุกสถานะ
- แสดง 10 งานต่อหน้า เรียงงานที่สร้างล่าสุดก่อน

## 5. สับสนช่วยหน่อย — สุ่มช่วยตัดสินใจ

**ใช้ทำอะไร:** สร้างกลุ่มรายการ (เช่น "ร้านอาหารแถวบ้าน" "ที่เที่ยว") แล้วให้ระบบสุ่มให้ รายการที่สุ่มได้แล้วจะไม่ออกซ้ำจนกว่าจะเริ่มใหม่

มี 2 แท็บ: **สุ่ม** และ **จัดการกลุ่ม**

### เตรียมข้อมูล (แท็บ "จัดการกลุ่ม")
1. กดปุ่ม **เพิ่มกลุ่ม** ตั้งชื่อกลุ่ม (ไม่เกิน 50 ตัวอักษร ห้ามซ้ำ)
2. เข้าไปในกลุ่ม เพิ่มรายการทีละรายการ (ไม่เกิน 100 ตัวอักษร)
3. แก้ไข/ลบกลุ่มและรายการได้ การลบกลุ่มจะลบรายการในกลุ่มด้วย (มีกล่องยืนยัน)

### สุ่ม (แท็บ "สุ่ม")
1. ติ๊กเลือกกลุ่มที่ต้องการ เลือกได้ **หลายกลุ่ม** ระบบจะรวมรายการทั้งหมดเป็นกองเดียว
2. กดปุ่มสุ่ม ผลล่าสุดแสดงชัดเจน
3. รายการที่สุ่มได้จะย้ายไปอยู่ในรายการ "สุ่มไปแล้ว" และไม่ถูกสุ่มซ้ำ
4. เมื่อรายการหมดกอง ระบบแนะนำให้กด **เริ่มสุ่มใหม่** เพื่อคืนทุกรายการกลับเข้ากอง

**ข้อควรรู้**
- เปลี่ยนกลุ่มที่เลือกระหว่างสุ่ม = เริ่มสุ่มใหม่อัตโนมัติ
- ผลการสุ่มที่ผ่านมา **ไม่ถูกบันทึกถาวร** รีเฟรชหน้าแล้วหาย (แต่กลุ่มและรายการที่สร้างไว้ยังอยู่)
- ตัวอย่างการใช้งาน: เมื่อเลือก 😩/😭 ใน "ตัวฉันวันนี้" มีลิงก์ลัดมาที่นี่ให้สุ่ม "เมนูฮีลใจ" ได้

## 6. เงินฉันไปไหน — รายรับ-รายจ่าย

**ใช้ทำอะไร:** จดรายรับ-รายจ่ายเป็นบาท ดูสรุปว่าใช้ไปกับอะไรมากที่สุด

มี 3 แท็บ: **บันทึกรายการ · สรุป · หมวดหมู่**

### หมวดหมู่
- ครั้งแรกที่เปิด ระบบใส่หมวดเริ่มต้นให้
  - รายรับ: เงินเดือน, งานฟรีแลนซ์, การลงทุน, รายรับอื่น ๆ
  - รายจ่าย: อาหารและเครื่องดื่ม, การเดินทาง, ช้อปปิ้ง, ค่าสาธารณูปโภค, ความบันเทิง, สุขภาพ, รายจ่ายอื่น ๆ
- เพิ่ม/แก้ไขชื่อ/ลบหมวดของตัวเองได้ ชื่อห้ามซ้ำภายในประเภทเดียวกัน
- **แก้ประเภท (รายรับ↔รายจ่าย) ของหมวดที่สร้างแล้วไม่ได้**
- **ลบหมวดที่มีรายการอ้างอิงอยู่ไม่ได้** ระบบจะบอกเหตุผล ให้ย้ายหรือลบรายการเหล่านั้นก่อน

### บันทึกรายการ
1. เปิดส่วน "เพิ่มรายการ" (กดลูกศรมุมขวาบนเพื่อกางออก — ค่าเริ่มต้นพับอยู่)
2. เลือก **ประเภท** (รายรับ/รายจ่าย) ก่อน แล้วเลือก **หมวดหมู่** (จะเห็นเฉพาะหมวดของประเภทนั้น)
3. เลือก **วันที่** (ค่าเริ่มต้นวันนี้ ย้อนหลังได้ **อนาคตไม่ได้**)
4. กรอก **จำนวนเงิน** (ต้องมากกว่า 0) และคำอธิบาย (ไม่บังคับ ไม่เกิน 200 ตัวอักษร)
5. กดบันทึก ฟอร์มจะล้างค่าให้พร้อมจดรายการต่อไป
6. ใต้ฟอร์มแสดง 10 รายการล่าสุด แก้ไข/ลบได้ และกรองดูตามประเภท (ทั้งหมด/รายรับ/รายจ่าย)

### สรุป
- การ์ดด้านบน: **รายรับรวม · รายจ่ายรวม · จำนวนรายการ** (ไม่มียอดคงเหลือ)
- **ยอดรวมแยกตามหมวด** ดูได้ว่าหมวดไหนใช้มากที่สุด
- **ตารางประวัติ** เรียงวันที่ล่าสุดก่อน แสดง 10 รายการต่อหน้า แก้ไข/ลบได้
- **ตัวกรอง** (กดลูกศรเพื่อกางออก): ช่วงวันที่, เดือน/ปี, ประเภท, หมวดหมู่, ค้นหาจากคำอธิบาย และปุ่ม **ล้างตัวกรอง** การ์ดสรุปคำนวณตามตัวกรองที่เลือก
- ถ้าเลือก "เดือน/ปี" ระบบจะใช้แทนช่วงวันที่
- ถ้าตัวกรองยังทำงานอยู่ ส่วนตัวกรองจะแสดง "กำลังกรองอยู่" แม้พับเก็บไว้

## 7. ผอมไปด้วยกัน — แคลอรี่

**ใช้ทำอะไร:** คำนวณพลังงานที่ร่างกายใช้ต่อวัน และจดแคลอรี่จากอาหารที่กิน เทียบกับเป้าหมาย

มีแท็บ **บันทึกอาหาร · สรุป · BMR/TDEE** และไอคอนตั้งค่าเพื่อเข้าไปจัดการ **รายการอาหาร**

> ตัวเลขทั้งหมดเป็น **ค่าประมาณ** ไม่ใช่คำแนะนำทางการแพทย์

### BMR/TDEE (ควรทำก่อน)
- **BMR** = พลังงานที่ร่างกายใช้ขณะพักต่อวัน **TDEE** = พลังงานที่ใช้รวมกิจกรรมต่อวัน
1. กรอก เพศ, อายุ (10–100 ปี), น้ำหนัก (20–300 กก.), ส่วนสูง (100–250 ซม.)
2. เลือก **ระดับกิจกรรมประจำวัน** จากเมนู 5 ระดับ (ตั้งแต่นั่งทำงานเป็นหลักไปจนถึงออกแรงหนักมาก)
3. กดคำนวณ ระบบแสดง BMR และ TDEE เป็น กิโลแคลอรี่ต่อวัน และ **บันทึกเป็นโปรไฟล์ของคุณ** ไว้ใช้เทียบในหน้าอื่น
4. ถ้ากรอกค่านอกช่วง จะมีข้อความใต้ช่องที่ผิดและไม่คำนวณ

### บันทึกอาหาร
1. เลือกวันที่ (ค่าเริ่มต้นวันนี้) หรือเลื่อนวันก่อนหน้า/ถัดไป
2. ค้นหาและเลือกอาหารจากรายการ (มีให้ตั้งต้น 102 เมนู) ระบบแสดง "กี่ kcal ต่อ 1 หน่วย" ให้ทันที ไม่ต้องกรอกเอง
3. เลือก **มื้อ** (เช้า/กลางวัน/เย็น/ของว่าง) และ **จำนวนหน่วย** (ค่าเริ่มต้น 1, ใส่ทศนิยมได้ เช่น 0.5, ไม่เกิน 100)
4. ฟอร์มแสดงแคลอรี่ของรายการนี้สด ๆ ก่อนกดบันทึก
5. รายการแสดงจัดกลุ่มตามมื้อ พร้อมยอดรวมรายมื้อและรวมทั้งวัน เทียบกับ TDEE ของคุณ
6. แก้ไขได้ (จำนวน มื้อ วันที่) และลบได้ (มีกล่องยืนยัน)

**ข้อควรรู้**
- รายการที่จดไว้ **เก็บสำเนาชื่อ หน่วย และแคลอรี่ ณ ตอนที่กิน** ถ้าภายหลังแก้หรือลบอาหารในรายการ ประวัติเดิมไม่เปลี่ยน
- อาหารตั้งต้นมีป้าย **"ค่าโดยประมาณ"**
- ถ้ายังไม่ได้คำนวณ BMR/TDEE จะมีลิงก์พาไปทำก่อน

### สรุป
- สลับ **รายสัปดาห์** (จันทร์–อาทิตย์) หรือ **รายเดือน** เลื่อนย้อนหลังได้ไม่จำกัด ไปข้างหน้าได้ถึงช่วงปัจจุบัน
- แสดง แคลอรี่รวม, ค่าเฉลี่ยต่อวัน, จำนวนวันที่จด, เป้าหมาย TDEE พร้อมส่วนต่าง
- **ค่าเฉลี่ยคิดเฉพาะวันที่มีบันทึก** เพื่อไม่ให้วันที่ลืมจดทำให้ค่าเฉลี่ยต่ำเกินจริง
- มีแถบรายวันเทียบกับ TDEE และสัดส่วนแคลอรี่แยกตามมื้อ

### รายการอาหาร (ไอคอนตั้งค่า)
- ค้นหา เพิ่ม แก้ไข ลบ อาหาร (ชื่อ ≤ 100 ตัวอักษร, หน่วย เช่น จาน/ถ้วย/ชิ้น ≤ 20 ตัวอักษร, แคลอรี่ต่อ 1 หน่วย 0–10,000)
- ชื่ออาหารห้ามซ้ำ แสดง 10 รายการต่อหน้า
- ถ้าลบอาหารจนหมดทุกรายการ ระบบจะใส่ชุดเริ่มต้นกลับมาให้เมื่อเปิดหน้านี้ครั้งถัดไป

## 8. อันไหนถูกกว่า บอกมา — เทียบราคาต่อหน่วย

**ใช้ทำอะไร:** ตอนซื้อของ กรอกราคาและปริมาณของแต่ละตัวเลือก ระบบบอกว่าตัวไหนคุ้มที่สุด **ไม่บันทึกข้อมูลใด ๆ**

1. มีให้ 2 ตัวเลือกเคียงข้างกัน กดปุ่มเพิ่มได้ถึง 3 ตัวเลือก ลบได้เมื่อมีเกิน 2
2. แต่ละตัวเลือกกรอก: **ชื่อ** (ไม่บังคับ เช่น "ยี่ห้อ A"), **ราคา** (บาท), **ปริมาณ**, **หน่วย**
3. หน่วยที่เลือกได้

| กลุ่ม | หน่วย |
|---|---|
| น้ำหนัก | มก. / ก. / กก. |
| ปริมาตร | มล. / ล. |
| นับจำนวน | ชิ้น |

4. กดปุ่ม **เปรียบเทียบ** ผลจะแสดงเมื่อกดเท่านั้น และถูกล้างทันทีถ้าคุณแก้ข้อมูลหรือเพิ่ม/ลบตัวเลือก (ต้องกดใหม่)
5. ผลลัพธ์: ราคาต่อหน่วยของแต่ละตัวเลือก, ป้ายเขียว **"คุ้มที่สุด"** ที่ตัวที่ถูกสุด, ตัวอื่นบอก **"แพงกว่า X%"**
6. เปลี่ยน **หน่วยผลลัพธ์** ได้ (เช่น ต่อ 1 ก. / ต่อ 100 ก. / ต่อ 1 กก. — ค่าเริ่มต้นคือต่อ 100) ตัวเลขเปลี่ยนทันที แต่ลำดับความคุ้มไม่เปลี่ยน

**ข้อควรรู้**
- เทียบได้เฉพาะ **กลุ่มหน่วยเดียวกัน** (กรัมกับกิโลกรัมเทียบได้ แต่กรัมกับมิลลิลิตรเทียบไม่ได้ ระบบจะอธิบายและไม่จัดอันดับ)
- ถ้าซื้อเป็นแพ็ก (เช่น 6 กระป๋อง × 330 มล.) ให้กรอก **ปริมาณรวม** เอง (1,980 มล.) ไม่มีช่องจำนวนแพ็ก
- ตัวเลือกที่กรอกไม่ครบจะไม่ถูกนำไปจัดอันดับ และมีข้อความบอกว่าขาดอะไร ต้องมีตัวเลือกที่ครบอย่างน้อย 2 ตัว
- ถ้าราคาต่อหน่วยเท่ากัน ระบบแสดง "ราคาเท่ากัน"
- ราคาและปริมาณต้องมากกว่า 0 และไม่เกิน 1,000,000 (ราคาทศนิยมไม่เกิน 2 ตำแหน่ง) ชื่อไม่เกิน 50 ตัวอักษร
- โปรโมชั่นอย่าง "ซื้อ 1 แถม 1" ให้คำนวณปริมาณรวมเอง

## 9. อย่าลืมฉัน — เอกสารหมดอายุ ซ่อมบำรุง ค่าสมาชิก

**ใช้ทำอะไร:** จดเรื่องที่มักลืม เช่น บัตร/พาสปอร์ต/ใบขับขี่ พรบ./ประกันรถ ล้างแอร์ เปลี่ยนไส้กรองน้ำ ค่าสมาชิกรายเดือน/รายปี กรอกครั้งเดียว ระบบคำนวณวันครบกำหนดถัดไปให้

> **การเตือนทำงานในแอปเท่านั้น** ต้องเปิดแอปจึงจะเห็น ไม่มีการแจ้งเตือนเข้ามือถือ อีเมล หรือ LINE

### หน้ารายการ
- แถบสรุปด้านบน: **เลยกำหนด · ถึงเกณฑ์เตือน · ค่าใช้จ่ายเดือนหน้า**
- รายการเรียงตามวันครบกำหนดใกล้สุดก่อน
- 2 แท็บ: **ใช้งานอยู่** และ **เก็บถาวร**

### สีบอกความเร่งด่วน
| สี | ความหมาย |
|---|---|
| แดง | เลยกำหนดแล้ว หรือเหลือน้อยกว่า 7 วัน (หรือถึงระยะที่ตั้งไว้แล้ว) |
| เหลือง | เหลือ 7–30 วัน |
| เขียว | เหลือมากกว่า 30 วัน |

ทุกสีมีข้อความกำกับด้วย ไม่ต้องดูสีอย่างเดียว

### เพิ่มรายการ
1. กดปุ่ม **เพิ่มรายการ** (ไอคอน +) ด้านบน
2. เลือก **หมวด**: เอกสารราชการ / ยานพาหนะ / ของใช้ในบ้าน / รักษาพยาบาล / สมาชิก-ค่าบริการ / อื่น ๆ (ช่องที่ให้กรอกจะเปลี่ยนตามหมวด)
3. กรอก **ชื่อรายการ** (ไม่เกิน 100 ตัวอักษร)
4. ตั้ง **วันครบกำหนด** ทำได้ 2 วิธี
   - เลือกจากปฏิทิน
   - พิมพ์ **"อีกกี่วัน"** (0–36,500 นับจากวันนี้) ระบบเติมวันที่ให้และแสดงวันที่เต็ม
5. (ไม่บังคับ) **รอบทำซ้ำ**: ทุก N วัน/เดือน/ปี ถ้าไม่ตั้ง = ครั้งเดียว
6. (ไม่บังคับ) **เตือนล่วงหน้า** เลือกได้ **1 ระดับ**: กดปุ่มสำเร็จรูปของหมวด หรือพิมพ์จำนวนวันเอง (0–730) แล้วกด + ; กดอันใหม่ = แทนที่, กดอันที่เลือกอยู่ซ้ำ = ไม่ตั้งเตือน ฟอร์มจะแสดง "วันที่เตือน" ที่คำนวณได้
7. (ไม่บังคับ) ค่าใช้จ่ายโดยประมาณ, ผู้ให้บริการ/ช่าง + เบอร์โทร, หมายเหตุ (ไม่เกิน 500 ตัวอักษร)
8. (ไม่บังคับ) **ตามระยะทาง/การใช้งาน** เช่น ถ่ายน้ำมันเครื่องทุก 10,000 กม. : กรอกหน่วย, ทุกกี่หน่วย, ค่าที่ทำครั้งล่าสุด, ค่าปัจจุบัน (คุณอัปเดตเลขเองเป็นระยะ) รายการจะครบกำหนดเมื่อ **ถึงวันที่ หรือ ถึงระยะ** อย่างใดอย่างหนึ่งก่อน

ชุดเตือนล่วงหน้าสำเร็จรูป (วัน): เอกสาร 180/90/30 · ยานพาหนะ 30/7 · ของใช้ในบ้าน 7/1 · รักษาพยาบาล 30/7/1 · สมาชิก 3/1 · อื่น ๆ 7/1

### กด "ทำแล้ว" (ต่ออายุ/ซ่อมบำรุงเสร็จแล้ว)
1. กดปุ่ม **ทำแล้ว** ที่การ์ดรายการ
2. กรอก วันที่ทำ (ค่าเริ่มต้นวันนี้), ค่าใช้จ่ายจริง, ผู้ให้บริการ/เบอร์โทร, หมายเหตุ, ค่าระยะตอนนี้ (ถ้าตั้งตามระยะ)
3. ระบบบันทึกลงประวัติ แล้ว
   - **มีรอบทำซ้ำ:** วันครบกำหนดใหม่ = วันที่ทำ + รอบ (แก้ได้ก่อนบันทึก) เช่น 31 ม.ค. + 1 เดือน = สิ้นเดือน ก.พ.
   - **ไม่มีรอบ:** ช่อง "วันครบกำหนดครั้งถัดไป" **กรอก = เลื่อนวัน, เว้นว่าง = เก็บถาวร** (ย้ายไปแท็บ "เก็บถาวร")

### ประวัติ
กดที่การ์ดเพื่อเปิดประวัติ เห็นวันที่ทำ ค่าใช้จ่าย ผู้ให้บริการ เบอร์โทร หมายเหตุ เรียงใหม่ไปเก่า รายการที่เก็บถาวรยังดูประวัติได้

### ค่าใช้จ่ายเดือนหน้า
รวมค่าใช้จ่ายของรายการที่ครบกำหนด **ในเดือนปฏิทินถัดไป** (รวมรอบที่จะซ้ำในเดือนนั้น) รายการที่ไม่ได้ใส่ค่าใช้จ่ายไม่นับ และระบบบอกว่ามีกี่รายการที่ไม่มีราคา

### ลบรายการ
**ลบรายการ = ลบประวัติของรายการนั้นทั้งหมดด้วย** กล่องยืนยันจะบอกไว้ ถ้าไม่อยากเสียประวัติให้ใช้ "ทำแล้ว" แบบไม่ใส่วันถัดไปเพื่อเก็บถาวรแทน

## 10. ไซส์ไหนคือฉัน — แปลงไซส์เสื้อผ้า/รองเท้า

**ใช้ทำอะไร:** ตอนสั่งของจากต่างประเทศ บันทึกสัดส่วนจริงของตัวเอง (หรือคนรอบตัว) ไว้ครั้งเดียว ระบบแปลงเป็นไซส์ของแต่ละมาตรฐาน (US / UK / EU / JP / KR / CN) ให้ทันที

> ผลลัพธ์ทุกค่าเป็น **ค่าประมาณ** ไซส์จริงของแบรนด์อาจต่างไปครึ่งไซส์ถึงหนึ่งไซส์ (โดยเฉพาะไซส์ญี่ปุ่น) เหมาะกับวัยรุ่นและผู้ใหญ่ **ไม่มีไซส์เด็ก**

มี 3 แท็บ: **ตัวแปลง · โปรไฟล์ · จดไซส์**

### โปรไฟล์ (สัดส่วนร่างกาย)
1. ไปแท็บ **โปรไฟล์** กดเพิ่ม ตั้งชื่อ (1–50 ตัวอักษร ห้ามซ้ำ เช่น "ฉัน" "แฟน") เลือกกลุ่ม **ผู้ชาย/ผู้หญิง**
2. กรอกสัดส่วนเท่าที่รู้ ทุกช่อง **ไม่บังคับ**

| ช่อง | ช่วงที่รับ |
|---|---|
| ความสูง | 30–250 ซม. |
| ความยาวเท้า | 5–40 ซม. |
| ความกว้างหน้าเท้า | 3–20 ซม. |
| รอบอก / รอบเอว / รอบสะโพก | 20–250 ซม. |
| รอบศีรษะ | 30–80 ซม. |
| รอบนิ้ว (แหวน) | 30–100 มม. |

3. สลับหน่วย **ซม./นิ้ว** ได้ที่ช่องกรอก ระบบเก็บเป็นซม.เสมอ
4. สร้างได้หลายโปรไฟล์ แก้ไข/ลบได้ การลบโปรไฟล์จะลบบันทึก "จดไซส์" ของโปรไฟล์นั้นด้วย (มีกล่องยืนยัน)
5. แอปไม่มีคู่มือวัดตัว ให้วัดตามวิธีที่ร้านหรือแบรนด์แนะนำ

### ตัวแปลง
1. เลือก **โปรไฟล์** (ค่าเริ่มต้นคือ "กรอกเอง (ไม่บันทึก)" ใช้ลองกรอกค่าของคนอื่นชั่วคราวได้โดยไม่ต้องสร้างโปรไฟล์)
2. เลือก **หมวด**: รองเท้า · เสื้อ · กางเกง · แหวน · หมวก
3. ระบบแสดงตารางเทียบทุกมาตรฐานพร้อมกัน ถ้าค่าตกกลางระหว่างสองไซส์ จะแสดงเป็นช่วง เช่น "EU 41.5–42"
4. ถ้าโปรไฟล์ยังขาดค่าที่หมวดนั้นต้องใช้ ระบบบอกว่าขาดช่องไหนพร้อมปุ่มไปกรอก (ไม่เดาให้)
5. **เผื่อไซส์** (ไม่บันทึกลงบัญชี): เสื้อผ้า/กางเกงเลือก "พอดีตัว/ปกติ" หรือ "Oversize" (+1 ไซส์), รองเท้าเลือก "ปกติ" หรือ "หน้าเท้ากว้าง" (+ครึ่งไซส์) ระบบแสดงทั้ง **ไซส์ตามตัวเลข** และ **ไซส์ที่แนะนำ** พร้อมเหตุผล

**ข้อควรรู้เฉพาะหมวด**
- **รองเท้า:** ถ้าเท้าเล็กกว่าช่วงไซส์ผู้ใหญ่ จะแสดงเฉพาะ JP/CN/KR พร้อมข้อความให้ใช้ตารางไซส์เด็กของแบรนด์
- **แหวน:** กรอกได้ทั้งรอบนิ้วหรือเส้นผ่านศูนย์กลางด้านใน ระบบแสดงทั้งเบอร์แบบ ISO/JP และแบบ EU (เส้นรอบวงตรง ๆ) พร้อมป้ายกำกับกันสับสน ไม่มีเบอร์มาตรฐานของไทย
- **กางเกง:** ถ้าค่ารอบเอวและสะโพกชี้คนละไซส์ ระบบเลือกไซส์ใหญ่กว่าและบอกเหตุผล ไซส์ยีนส์เป็นค่าประมาณ ป้ายไซส์จริงมักไม่ตรงขนาดจริง
- ค่าที่อยู่นอกตารางจะแสดง "ใหญ่/เล็กกว่าตาราง" ไม่เดา
- ยังไม่มีตารางไซส์รายแบรนด์ และไม่มีหมวดกระโปรง

### จดไซส์ (ไซส์ที่เคยใส่ได้จริง)
1. แท็บ **จดไซส์** เลือกโปรไฟล์ กดเพิ่ม
2. กรอก **แบรนด์** (ต้องกรอก ≤ 50 ตัวอักษร), สินค้า/รุ่น (ไม่บังคับ), **ไซส์ที่ใส่** (เช่น "US 9" ≤ 30 ตัวอักษร), ความรู้สึก (**พอดี/คับ/หลวม**), หมายเหตุ
3. ค้นหา/กรองตามแบรนด์ได้ เรียงล่าสุดก่อน แก้ไข/ลบได้ (มีกล่องยืนยัน)
4. ใช้เป็นข้อมูลอ้างอิงของคุณเอง **ไม่ได้ไปปรับผลในตัวแปลงอัตโนมัติ**

## 11. ตัวฉันวันนี้ — เช็กอารมณ์ประจำวัน

**ใช้ทำอะไร:** เช็กใจตัวเองเร็ว ๆ ด้วยอิโมจิ แตะไม่กี่ครั้งก็เสร็จ ดูย้อนหลังเป็นปฏิทิน และดูสรุปรายเดือน

> แอปนี้ **ไม่ใช่เครื่องมือวินิจฉัยหรือรักษา** ข้อความให้กำลังใจเป็นข้อความสำเร็จรูป (ไม่ใช่ AI) หากรู้สึกหนักใจมาก ควรคุยกับคนที่ไว้ใจหรือผู้เชี่ยวชาญ

มี 4 แท็บ: **วันนี้ · ปฏิทิน · สรุปเดือน · ตั้งค่า**

### อารมณ์ 5 ระดับ
| อิโมจิ | ชื่อ | ความหมาย |
|---|---|---|
| 🤩 | เยี่ยมยอด | วันที่อะไรก็เป็นใจ เจอเรื่องดี ๆ |
| 😊 | สวยงาม | สบายใจ ไม่เครียด สุขเล็ก ๆ |
| 😐 | เฉย ๆ | วันปกติ แค่ผ่านไปอีกวัน |
| 😩 | แบตหมด | เรียนหนัก งานเยอะ นอนน้อย หมดพลัง |
| 😭 | ลงเหว | เครียดจัด เศร้า กดดัน อยากพักจากทุกอย่าง |

### เช็กอินวันนี้ (แท็บ "วันนี้")
1. **แตะอิโมจิ 1 ครั้ง = บันทึกอารมณ์ทันที** ไม่ต้องกดปุ่มบันทึก
2. (ไม่บังคับ) เลือก **แท็ก** ได้หลายข้อ แบ่งเป็น **เรื่องราว** (เช่น การเรียน/สอบ การเงิน เพื่อน ความรัก ครอบครัว สุขภาพ/การนอน) และ **กิจกรรม** (เช่น กินของอร่อย ฟังเพลง ดูหนัง/ซีรีส์ ออกกำลังกาย ช้อปปิ้ง)
3. (ไม่บังคับ) พิมพ์ **ข้อความสั้น** ไม่เกิน 100 ตัวอักษร (มีตัวนับ)
4. กดปุ่ม **บันทึก** ถ้าสำเร็จ ระบบพาไปแท็บ **ปฏิทิน** ให้อัตโนมัติ
5. **วันละ 1 รายการ:** เช็กอินซ้ำในวันเดียวกัน = แก้รายการเดิม ไม่เพิ่มใหม่ ลบรายการของวันได้ (มีกล่องยืนยัน)
6. ถ้าวันนี้ยังไม่เช็กอิน จะมีแถบ **"วันนี้ยังไม่ได้เช็กอิน"** แสดงในหน้านี้ (ไม่มีการแจ้งเตือนนอกแอป)

### ปฏิทิน
- ตารางรายเดือน (เริ่มวันอาทิตย์) แต่ละวันแสดงอิโมจิของวันนั้น วันที่ยังไม่เช็กอินว่างอยู่ แต่ละระดับอารมณ์มีสีพื้นโทนหม่น
- เลื่อนเดือนก่อนหน้า/ถัดไปได้ (ไปข้างหน้าได้ไม่เกินเดือนปัจจุบัน)
- **กดวันที่** เพื่อดู/เพิ่ม/แก้ย้อนหลังในหน้าต่างเล็ก (Popup) กดบันทึกแล้วหน้าต่างปิดกลับมาที่ปฏิทิน **วันในอนาคตบันทึกไม่ได้**

### สรุปเดือน
การ์ดสรุปของเดือนที่เลือก:
- สัดส่วนอารมณ์ 5 ระดับเป็น % (คิดจากวันที่เช็กอินในเดือนนั้น)
- อารมณ์ที่เจอบ่อยที่สุด และจำนวนวันที่เช็กอิน
- แท็กที่เจอบ่อยที่สุด 3 อันดับ
- ข้อความให้กำลังใจ 1 ข้อความ เลือกตามอารมณ์เด่นของเดือน
- ถ้าเช็กอินน้อยกว่า 5 วัน แสดงการ์ดได้แต่มีหมายเหตุว่าข้อมูลยังน้อย เดือนที่ไม่มีข้อมูลแสดงข้อความชวนไปเช็กอิน
- **ไม่มีปุ่มแชร์การ์ด** (ตัดออกตามที่เจ้าของผลิตภัณฑ์ตัดสินใจ)

### ตั้งค่า (จัดการแท็กเอง)
1. แท็บ **ตั้งค่า** แสดงแท็กแยกเป็น 2 กลุ่ม: **เรื่องราว** และ **กิจกรรม**
2. **เพิ่ม** แท็กใหม่ในกลุ่มที่ต้องการ, **แก้ชื่อ**, หรือ **ลบ** ได้ทุกแท็ก (รวมแท็กเริ่มต้น 11 อัน)
3. ข้อจำกัด: ชื่อ 1–20 ตัวอักษร, ห้ามซ้ำในกลุ่มเดียวกัน, รวมกันไม่เกิน **30 แท็ก**
4. **ลบแท็กแล้ว แท็กนั้นจะหายจากการเช็กอินเก่าทุกวัน** ด้วย (สรุปเดือนของเดือนเก่าจะไม่นับแท็กนั้น) กล่องยืนยันจะเตือนไว้
5. แท็กเริ่มต้นถูกใส่ให้ตอนเปิดครั้งแรก ถ้าลบจนไม่เหลือเลยแล้วกลับมาเปิดใหม่ แท็กเริ่มต้นจะกลับมา
6. ถ้ายังไม่มีแท็กเลย หน้าเช็กอินจะมีข้อความชวนมาเพิ่มที่แท็บนี้

### เมื่อเลือก 😩 แบตหมด หรือ 😭 ลงเหว
- จะมี **การ์ดปลอบใจ** ข้อความสั้น ๆ พร้อมกิจกรรมเล็ก ๆ ที่ทำได้เลย (เช่น ดื่มน้ำ พักสายตา หายใจลึก ๆ) ปิดการ์ดได้ ไม่ต้องอ่านก็ได้
- มีลิงก์ไป **สุ่มเมนูฮีลใจ** ที่เครื่องมือ "สับสนช่วยหน่อย" (ต้องสร้างกลุ่มรายการไว้ก่อน)
- ถ้าเลือก 😭 **ติดต่อกัน 3 วันขึ้นไป** จะมีข้อความดูแลใจเบา ๆ แนะนำให้คุยกับคนที่ไว้ใจหรือผู้เชี่ยวชาญ พร้อมสายด่วนสุขภาพจิต กรมสุขภาพจิต **1323**

## 12. คำถามที่พบบ่อยและแก้ปัญหาเบื้องต้น

| คำถาม / อาการ | คำตอบ |
|---|---|
| ลืมรหัสผ่าน | ติดต่อผู้ดูแลระบบให้ตั้งรหัสใหม่ให้ (ยังไม่มีปุ่มลืมรหัสผ่าน) ข้อมูลไม่หาย |
| เปลี่ยนรหัสผ่านหรือแก้ชื่อ/อีเมลเองได้ไหม | ยังไม่ได้ ต้องติดต่อผู้ดูแล |
| สมัครไม่ผ่านบอกว่าซ้ำ | ชื่อผู้ใช้ อีเมล หรือเบอร์โทรมีคนใช้แล้ว ลองเปลี่ยนช่องที่ระบบแจ้ง |
| ข้อมูลหายไหมถ้าปิดเบราว์เซอร์ | ไม่หาย ข้อมูลอยู่กับบัญชีของคุณ (ยกเว้น "อันไหนถูกกว่า บอกมา" ที่ไม่บันทึกข้อมูล และผลการสุ่มของ "สับสนช่วยหน่อย") |
| เปิดบนอีกเครื่องแล้วเห็นข้อมูลเดิมไหม | เห็น เมื่อเข้าสู่ระบบด้วยบัญชีเดียวกัน |
| หน้าขึ้นข้อความผิดพลาด | กดปุ่ม **ลองใหม่** ถ้ายังไม่ได้ ตรวจอินเทอร์เน็ต แล้วรีเฟรชหน้า |
| กดบันทึกแล้วไม่ผ่าน มีข้อความใต้ช่อง | ค่าที่กรอกอยู่นอกเงื่อนไข เช่น ซ้ำ ยาวเกิน หรือเป็นวันในอนาคต แก้ตามข้อความ |
| ไม่เห็นการเตือนของ "อย่าลืมฉัน" | การเตือนแสดงเมื่อเปิดแอปเท่านั้น และรายการต้องตั้ง "เตือนล่วงหน้า" ไว้ |
| ตัวเลขแคลอรี่/ไซส์ไม่ตรงกับที่อื่น | เป็นค่าประมาณ ไม่ใช่ค่ารับประกัน โปรดตรวจกับแหล่งทางการหรือตารางของแบรนด์ |
| ลบแล้วกู้คืนได้ไหม | ไม่ได้ ระบบจึงถามยืนยันก่อนลบทุกครั้ง |
| ใช้ออฟไลน์ได้ไหม | ไม่ได้ ต้องมีอินเทอร์เน็ตเพื่อเข้าสู่ระบบและบันทึกข้อมูล |
